Archivos comunes: `common.js` (ciudad, titulares, subtítulos) y `head.html` (estilos). Cada parte: `guion.txt`, `voz.*`, `video.html`, `audio.json`, `musica.mp3`, `descripcion.txt`, `portada.png`.
